# Digitale Visitenkarte · Dr. Tobias Klur

Digitale Visitenkarte von Dr. Tobias Klur, M.Sc., Fachzahnarzt für Kieferorthopädie bei RANG + KLUR (Euskirchen + Mechernich).

Statische Seite ohne Build und ohne externe Dienste: Schrift (Cairo) und QR-Bibliothek liegen lokal, kein Tracking.

- `index.html`: die Karte (bewegtes Porträt, Wendeseite, Kontakt speichern, Standorte, QR-Code, Teilen)
- `kontakt.vcf`: Kontaktdatei mit Foto
- `media/`: bewegtes Porträt (MP4-Schleife) und Startbild
- `werkzeuge/`: Skripte zum Freistellen und Animieren des Porträts und zum Erstellen nahtloser Schleifen
